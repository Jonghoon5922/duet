Duet — 나와 Claude가 함께 하는 일의 보드
==========================================

처음 할 일
----------
1. Claude Code 창을 새로 엽니다. 설치할 때 연결해 두었으니 Duet이 붙습니다.
2. 평소처럼 일을 시킵니다. Claude가 알아서 타스크를 만들거나 붙고, 진행을 남기고, 끝내면 완료 보고를 합니다.
3. Claude 창이 열려 있는 동안 보드는 늘 켜져 있습니다. 브라우저에서 http://127.0.0.1:8737 을 열면 됩니다.
   Claude 창이 하나도 없을 때는 시작 메뉴 [Duet 보드]를 누르면 보드가 뜹니다 (10분 동안 안 보면 스스로 꺼집니다).

보드에서 할 수 있는 것
----------------------
- 프로젝트가 상자 하나, 타스크가 그 안의 줄입니다. 상자 머리를 누르면 접히고 다시 누르면 펴집니다.
- 타스크 줄을 누르면 설명·세션·진행 로그가 펼쳐집니다. 제목과 설명은 클릭해서 고칩니다.
- 상태는 세션에 따라 자동으로 정해집니다 (Waiting → Running → Done). 직접 정하고 싶으면
  드롭다운에서 Done·On hold·Cancelled 중 하나를 고릅니다 (자물쇠가 붙습니다). 자물쇠를 누르면 다시 자동입니다.
  Claude가 일하는 중인 타스크는 잠겨서 손댈 수 없습니다 — 끝나면 풀립니다.
- 창을 그냥 닫은 세션은 "Needs review"로 남습니다. 세션 줄에서 Done으로 바꾸거나, 새 창에서 이어받습니다.
- 상자 머리의 [+ Task]로 타스크를 더하고, [Archive]로 끝난 프로젝트를 상자째 치웁니다 (지우지 않습니다.
  오른쪽 위 [Archived]에서 보고 [Unarchive]로 되돌립니다). [×]는 지웁니다 — 확인창을 거칩니다.
- 오른쪽 위 [+ New Project]는 이름과 첫 타스크를 받습니다. [Feedback]은 GitHub 이슈 화면을 채워서 엽니다.

Claude에게 이렇게 말하면 됩니다
--------------------------------
- "○○ 만들어줘"            → 타스크를 만들고 붙어서 일하고, 끝나면 완료 보고
- "○○ 계획 세워줘"         → 계획을 보여주면서 그 자리에서 타스크를 만듦
- "T003 이어서 해줘"        → 앞 세션이 남긴 로그를 읽고 이어받음
- "여기까지만 하자"         → 세션을 멈춤. 타스크는 Needs review로 남아 다음 창이 이어받음
- "duet 도구 있어?"         → 연결됐는지 확인 (타스크 목록이 나오면 정상)

기록은 어디에
-------------
내 사용자 폴더\.duet 에 폴더와 파일로 쌓입니다. 탐색기에서 열어 그대로 읽고 고쳐도 됩니다.
프로젝트는 세션이 뜬 폴더 이름으로 저절로 묶입니다. 다른 이름으로 부르고 싶으면
.duet\프로젝트.md 에 "C:\project\bookshelf = 서재" 처럼 한 줄 적습니다.

다른 앱에 연결
--------------
설치 폴더의 duet.exe 로:
  duet.exe list                    어느 앱에 붙어 있는지
  duet.exe register claude-desktop Claude Desktop에 연결
  duet.exe register cursor         Cursor에 연결
  duet.exe unregister cursor       연결 해제

지울 때
-------
제어판(앱 > 설치된 앱)에서 Duet을 제거하면 실행 파일과 앱 연결이 지워집니다.
기록(.duet 폴더)은 남습니다. 필요 없으면 직접 지우세요.
